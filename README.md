# High5Girls - Go to Programming
Together we'll learn to build our own website.

## Requirements
For running the repository, the following installations are required:

### Backend
The backend runs on python using uv as runtime/toolchain and package manager. You can learn more about uv here:
https://docs.astral.sh/uv/

To install follow the guide here: https://docs.astral.sh/uv/getting-started/installation/

On Mac we recommend using Homebrew:
```
brew install uv
```

### Frontend
The frontend runs on node.js using npnm as package manager. You can learn more about npnm here: https://pnpm.io/

To install follow the guide here: https://pnpm.io/installation

On mac we recommend using Homebrew
```
brew install pnpm
```

## Start
To run the program, go to terminal and run
```bash
bash start.sh
```
Open this link to see the website: [http://localhost:5173/](http://localhost:5173/)

## Stop
To stop it, click `CLTR + C`.
